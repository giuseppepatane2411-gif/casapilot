# Aggiornamento CasaPilot

Versione corrente: **Pilot OS v2 — Command Center**.

La base comprende wizard, dashboard, immobili, documenti, Health Score e Pilot OS interattivo.

Per avviare il progetto:

```powershell
cd app
npm install
npm run dev
```

Aprire quindi:

```text
http://localhost:3000/dashboard/pilot
```

Le novità complete sono descritte in `AGGIORNAMENTO_PILOT_OS_V2.md`.
