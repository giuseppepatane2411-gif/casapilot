# CasaPilot — UX Primo Minuto v3

Obiettivo: fare in modo che un nuovo utente capisca cosa fare nei primi 60 secondi senza dover imparare CasaPilot.

## Cosa cambia

- La prima schermata senza immobili non chiede più di “aggiungere una pratica”: chiede semplicemente **cosa vuoi fare con il tuo immobile?**
- Due scelte immediate: **Vendere** oppure **Affittare**.
- La scelta viene passata direttamente al wizard e il passaggio “obiettivo” viene saltato: l’utente arriva subito alle informazioni dell’immobile.
- Se esiste già una bozza, la bozza ha sempre la precedenza e non viene sovrascritta.
- Dopo aver completato il wizard compare un messaggio di orientamento: **il tuo percorso è pronto; guarda sempre Il prossimo passo**.
- Il percorso iniziale è raccontato in tre frasi: scegli obiettivo → racconta la casa → ricevi il prossimo passo.

## Principio UX

CasaPilot non deve chiedere all’utente di capire il software prima di ricevere valore.
Il primo valore deve arrivare il prima possibile.
