# Archivio locale — note importanti

L’Archivio locale usa IndexedDB del browser. I file non vengono inviati a un server.

## Formati supportati

- PDF
- JPG/JPEG
- PNG
- WEBP

Limite: 15 MB per file.

## Backup

Il backup JSON di CasaPilot include pratiche, checklist, memoria di Pilot, timeline, sessioni e feedback. Non include i file binari presenti in IndexedDB.

Conservare sempre i documenti originali fuori da CasaPilot.

## Cancellazione

La funzione “Cancella tutti i dati locali” nelle Impostazioni elimina anche l’Archivio locale. Anche la cancellazione dei dati del sito dal browser può rimuovere i file.
