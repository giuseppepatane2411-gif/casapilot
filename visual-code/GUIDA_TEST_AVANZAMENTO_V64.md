# Test rapido v6.4 — Avanzamento realistico

## Test 1 — Wizard

1. Crea un nuovo immobile.
2. Arriva al passaggio Posizione.
3. Verifica che non compaia più “80% pratica”.
4. Deve comparire “Configurazione iniziale” e “Passaggio 3 di 5”.
5. Leggi la nota: la barra riguarda soltanto la scheda iniziale.

## Test 2 — Scheda completa, nessun documento

1. Completa dati, indirizzo e conferma la mappa.
2. Non selezionare documenti.
3. Salva la casa.
4. Nella dashboard il percorso verso vendita/affitto dovrebbe essere vicino al 12%.
5. La fase attuale deve essere “Documenti e verifiche”.

## Test 3 — Documenti

1. Segna uno o più documenti come disponibili.
2. Torna alla dashboard.
3. La percentuale deve crescere in base al peso dei documenti.
4. Un documento importante può incidere più di un documento secondario.

## Test 4 — Riferimenti catastali

1. Segna la visura catastale come disponibile.
2. Lascia vuoti foglio, particella/mappale e subalterno.
3. Pilot deve proporre di riportare i riferimenti dalla visura.
4. Compilandoli, la fase documentale deve avanzare ulteriormente.

## Test 5 — Obiettivo diverso

1. Crea una pratica di vendita e una di affitto.
2. Apri “Vedi come viene calcolato”.
3. Verifica che nomi e pesi delle fasi successive siano diversi.
4. Le missioni finali devono parlare di proposta/chiusura per la vendita e di inquilino/contratto/consegna per l’affitto.
