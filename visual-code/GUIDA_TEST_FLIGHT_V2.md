# Guida rapida al Test Flight

## Obiettivo

Capire se CasaPilot rende chiaro il prossimo passo immobiliare prima di investire in OpenAI, backend o pubblicità.

## Test ideale: 8 minuti

1. Apri `Dashboard > Test Flight`.
2. Scegli lo scenario più vicino alla situazione del tester.
3. Leggi la missione principale senza spiegazioni esterne.
4. Completa la missione oppure allega un file di prova nell’Archivio locale.
5. Controlla se Health Score, timeline e missione successiva cambiano.
6. Lascia il feedback dalla sezione `Feedback beta`.
7. Condividi il feedback o esporta il report locale.

## Regola per chi osserva

Non spiegare CasaPilot durante i primi tre minuti. Annota:

- dove il tester si ferma;
- quali parole non comprende;
- quale pulsante prova a premere;
- quando capisce il valore del prodotto;
- se la missione gli sembra credibile.

## Prima soglia di validazione

Raccogliere almeno cinque test completi e verificare che:

- almeno 3 tester su 5 raggiungano Pilot senza aiuto;
- almeno 3 tester su 5 completino una missione;
- chiarezza media almeno 4/5;
- almeno 2 tester rispondano “Sì” alla disponibilità a pagare;
- emerga una parte del prodotto citata spontaneamente come utile.
