# Test rapido posizione v6.3

- Comune: digitazione parziale e selezione suggerimento.
- Via: ricerca abilitata solo dopo il Comune.
- CAP: 5 cifre e compilazione automatica quando disponibile.
- Fallback: uso manuale del testo se non compaiono risultati.
- Mappa desktop: trascinamento, tocco/click, zoom.
- Mappa mobile: trascinamento con dito.
- Geolocalizzazione: consenso browser e posizionamento.
- Conferma: stato verde e descrizione del punto.
- Modifica: una variazione annulla la precedente conferma.
- Compatibilità: apertura di una pratica creata prima della v6.3.
