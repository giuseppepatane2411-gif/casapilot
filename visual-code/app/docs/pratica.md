# PRATICA IMMOBILIARE

## Cos'è

La pratica è il cuore di Guimmia.

Ogni obiettivo dell'utente genera una pratica.

Esempi:

- Vendita appartamento
- Affitto villa
- Acquisto prima casa
- Gestione documentazione
